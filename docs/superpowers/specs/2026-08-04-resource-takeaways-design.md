# Вижимка ресурсу: головні тейки в бібліотеці

Дата: 2026-08-04
Статус: затверджено до імплементації

## 1. Проблема

Кожна AI-рекомендація приносить із собою список літератури — книги, курси, статті. Ресурс описаний назвою, автором, роком і одним реченням `note`. Цього достатньо, щоб зрозуміти, про що матеріал, але недостатньо, щоб вирішити головне: **чи варто витрачати на нього час**.

Книга — це десятки годин. Курс — інколи більше. Рішення «читати чи ні» користувач сьогодні приймає з одного речення або гуглить назву окремо, залишаючи застосунок.

Ціль зміни — дати до кожного ресурсу вижимку: головні тейки плюс одне речення про те, кому матеріал підійде, а кому ні. Читається за пів хвилини і безпосередньо відповідає на питання «чи варто».

## 2. Межі змін

**У межах:**

- нове поле `takeaways` у `LearningResource` та `AiResourceDTO`;
- генерація тейків у тому ж AI-виклику, що вже повертає ресурси;
- серверна санітизація тейків;
- тейки для всіх мок-ресурсів (шлях без ключа OpenAI);
- захисне читання поля зі сховища;
- кнопка-іконка з тултіпом у `ResourceList` та вкладена модалка;
- новий примітив `components/ui/tooltip.tsx`;
- оновлення `PROJECT_SPEC.md`, юніт- і e2e-тестів.

**Поза межами:**

- догенерація тейків на вимогу для ресурсів, збережених раніше (окремий роут; дизайн її не блокує, див. §8);
- редагування тейків користувачем;
- переклад тейків — інтерфейс і весь контент застосунку залишаються англійською.

## 3. Джерело даних

Тейки повертає **той самий AI-виклик, що вже повертає ресурси** — `/api/ai/recommendations` і `/api/ai/parse-intent`. Окремого роуту не додається.

Наслідок, прийнятий свідомо: ресурс без тейків не показує іконки взагалі. Це стосується всього, що вже лежить у `localStorage` до цієї зміни, і всього, де модель повернула невалідні тейки. Жодних станів завантаження, жодного порожнього стану в модалці, жодного другого роуту — за ціну того, що наявна бібліотека користувача залишиться без вижимок, поки він не додасть нові цілі.

Тейки генеруються для **усіх трьох типів** ресурсів. Питання «чи варто витрачати час» однаково актуальне для 40-годинного курсу, а однорідність іконки в списку важливіша за економію токенів на статтях.

## 4. Модель даних

`types/index.ts`:

```ts
export interface ResourceTakeaways {
  points: string[];
  fit: string;
}

export interface LearningResource {
  // ...наявні поля
  takeaways?: ResourceTakeaways;
}

export interface AiResourceDTO {
  // ...наявні поля
  takeaways: ResourceTakeaways | null;
}
```

`points` — 2-6 пунктів по суті матеріалу. `fit` — одне речення про те, кому підійде, а кому ні.

У `LearningResource` поле опційне: його наявність **і є** ознакою «показувати іконку». У DTO воно `| null`, узгоджено з рештою полів там (`author`, `year`, `url`).

Групування в об'єкт, а не два пласких поля, дає одну перевірку `resource.takeaways` замість двох і не допускає стану «є пункти, немає fit».

## 5. AI-шар

**`lib/ai/openai.ts`.** `RESOURCE_ITEM_SCHEMA` отримує вкладений об'єкт:

```ts
takeaways: {
  type: "object",
  additionalProperties: false,
  required: ["points", "fit"],
  properties: {
    points: {
      type: "array",
      items: { type: "string" },
      description: "4-6 concrete takeaways...",
    },
    fit: {
      type: "string",
      description: "One sentence on who should read this and who should skip it.",
    },
  },
}
```

`takeaways` додається до `required` кореневого `RESOURCE_ITEM_SCHEMA`. Strict-режим OpenAI не допускає необов'язкових властивостей, тому поле обов'язкове на рівні схеми, а відсіювання порожнього робить санітизація.

`RESOURCES_GUIDANCE` доповнюється двома реченнями: 4-6 тейків по суті матеріалу (не переказ анотації), і одне речення «кому підійде, кому ні».

**`lib/ai/resources.ts`.** Нова `sanitizeTakeaways(value: unknown): ResourceTakeaways | null`:

- не об'єкт → `null`;
- `points`: не масив → `null`; інакше кожен елемент через наявну `sanitizeText`, порожні відкидаються, решта обрізається до `MAX_TAKEAWAY_POINTS = 6`;
- менше 2 пунктів після чистки → `null`;
- `fit` порожній або не рядок → `null`;
- інакше `{ points, fit }`.

Викликається з `sanitizeResources` для кожного елемента. `toLearningResources` протягує поле далі без змін логіки.

Правило «обидва або нічого» вибране свідомо: модалка має передбачуваний вигляд, а частковий стан не потрапляє в сховище.

**`lib/ai/mock.ts`.** Усі мок-ресурси (~13 записів у `mockResources` та дефолтному наборі) отримують справжні тейки. Без цього фіча не існує для користувача без ключа OpenAI, а e2e-тестам нічого перевіряти — вони ганяють реальний флоу застосунку.

## 6. Сховище

`normalizeResources` у `lib/storage.ts` читає `takeaways` тим самим захисним способом, що й решту полів: перевірка структури, інакше `undefined`.

Міграція не потрібна. Поле опційне, ключ `todo-ai:v1` не змінюється, старі записи просто не мають іконки.

## 7. Інтерфейс

**Новий `components/ui/tooltip.tsx`** — обгортка Base UI (`Root`, `Trigger`, `Portal`, `Positioner`, `Popup`) у стилі решти `components/ui`: `data-slot`, `cn`, класи під наявні токени теми.

**Новий `components/resource-takeaways-dialog.tsx`** — контрольована модалка:

```
props: { resource: LearningResource | null; onClose: () => void }
```

Відкрита, коли `resource !== null`. Вміст: назва ресурсу заголовком, під ним автор і рік, далі `Key takeaways` списком, далі `Good fit if` абзацом.

**`components/resource-list.tsx`** — кнопка-іконка `Lightbulb` (`size="icon-sm"`, `variant="ghost"`), поруч із наявною `Trash2`. Рендериться **лише** за наявності `resource.takeaways`. Обгорнута тултіпом з текстом `Key takeaways`, `aria-label` виду `Key takeaways for "Clean Code"`.

Стан тримає сам `ResourceList`: один `useState<LearningResource | null>` і одна модалка на весь список. Жодне з чотирьох місць виклику (`library-tab`, `task-details-dialog`, `ai-recommendations-dialog`, `task-form-dialog`) не змінюється — ні пропсів, ні стану.

Відкинуті альтернативи: колбек `onOpenTakeaways` вимагав би однакової обв'язки в чотирьох файлах без вигоди; окрема модалка на рядок тримала б N порталів у DOM замість одного.

**Вкладення.** Три з чотирьох місць уже всередині діалогу. Base UI стекає діалоги штатно: вижимка лягає поверх, Escape закриває лише її, батьківська модалка залишається відкритою.

## 8. Розширюваність

Якщо відсутність вижимок у наявній бібліотеці виявиться незручною, догенерація на вимогу додається без переробки: новий роут приймає `{ kind, title, author, year }`, повертає той самий `ResourceTakeaways`, результат пишеться в той самий `resource.takeaways`. Модель даних, санітизація і модалка вже готові — змінюється лише умова рендеру іконки та додається стан завантаження в модалці.

## 9. Тестування

**Юніти.** `lib/ai/resources.test.ts`: валідні тейки проходять; менше 2 пунктів після чистки → `null`; порожній `fit` → `null`; понад 6 пунктів обрізається; не-об'єкт → `null`. `lib/storage.test.ts`: раунд-трип поля через сховище; ресурс, збережений без `takeaways`, завантажується як `undefined` без падіння.

**E2E.** `e2e/library.spec.ts`: після додавання плану іконка присутня в списку літератури; клік відкриває модалку з пунктами; Escape закриває її й повертає до списку.
